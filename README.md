# Исторический музей Согдийской области — Худжанд

Официальный веб-сайт Исторического музея Согдийской области, расположенного в стенах древней Худжандской крепости (Худжанд, Республика Таджикистан). Музейный фонд насчитывает более 28 000 уникальных экспонатов, охватывающих период от эпохи каменного века и основания Александрии Эсхаты до новейшей истории Таджикистана.

---

## 🌟 Основные особенности проекта

1. **Многоязычность (i18n)**:
   - Полная поддержка 3 языков: **Русский (РУ)**, **Таджикский (TJ)** и **Английский (EN)**.
   - Моментальное переключение языка без перезагрузки страницы на всех 6 страницах сайта.
   - Сохранение языковых предпочтений пользователя в `localStorage`.

2. **Аудио-дизайн и саундтрек**:
   - Атмосферная фоновая музыка (ambient) с кнопкой включения/выключения на всех страницах.
   - Автоматическое сохранение состояния проигрывания в `localStorage`.
   - Бесшовное возобновление звучания при переходах между страницами с учётом политик автовоспроизведения браузера.
   - Наличие локальной копии аудио (`audio/ambient.mp3`) и CDN-резерва.

3. **Реальные фотографии высокого разрешения**:
   - 37 уникальных проверенных фотографий с Unsplash без дублирования.
   - Индивидуальные описательные `alt`-тексты на русском языке для каждого экспоната и зала.
   - Все градиентные заглушки заменены реальными снимками цитадели, залов музея, золотых артефактов и экспозиций.

4. **Адаптивный и современный дизайн**:
   - Mobile-First подход с поддержкой планшетов и настольных экранов.
   - Страница экспозиций (`pages/expositions.html`) с адаптивной двухколоночной сеткой на десктопе и аккуратным стеком на смартфонах.
   - Интерактивная фотогалерея (`pages/gallery.html`) с фильтрацией по категориям (Крепость, Экспонаты, Залы музея, Панорамы, Мероприятия).

5. **Оптимизация и плавные анимации**:
   - Анимированный прелоадер с иконкой музея и `@keyframes spin`.
   - Плавное появление элементов при скролле (Scroll Reveal).
   - Анимация счётчиков статистики фонда и истории.
   - Кнопка быстрого возврата наверх («Back to Top»).
   - Валидация формы обратной связи.

## 🚀 Инструкция по развертыванию (Deployment)

Сайт представляет собой статический веб-проект (Pure HTML5, CSS3, Vanilla JS), не требующий сборки (`npm run build` не требуется).

### Способ 1: Деплой архива через Vercel / Netlify (Drag & Drop)
1. В корне проекта находится готовый архив: `khujand-museum-site.zip`.
2. **Netlify Drop**: Перейдите на [app.netlify.com/drop](https://app.netlify.com/drop) и просто перетащите `khujand-museum-site.zip` в окно браузера. Сайт будет опубликован через несколько секунд.
3. **Vercel**: Распакуйте архив или привяжите Git-репозиторий.

### Способ 2: Деплой через Vercel CLI
```bash
# Установка Vercel CLI (если не установлен)
npm i -g vercel

# Деплой из папки проекта
cd d:/Mysite1
vercel --prod
```

### Способ 3: GitHub Pages
1. Загрузите файлы в ветку `main`.
2. В настройках репозитория (Settings -> Pages) выберите источник `Deploy from a branch` -> `main` / `root`.
3. Сайт станет доступен по адресу `https://<username>.github.io/<repo>/`.

### Локальный просмотр
Откройте `index.html` прямо в браузере или запустите локальный HTTP-сервер:
```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

- **HTML5 Semantic**: Семантическая разметка с мета-тегами для SEO и социальными превью.
